# Joinville nos Trilhos: Locomotiva 3D & Cidade Inclusiva 🚂

Bem-vindo ao repositório do **Joinville nos Trilhos**, um simulador web 3D interativo, jogo educativo e plataforma de exploração de engenharia. O projeto é focado em acessibilidade universal (norma ABNT NBR 9050) e no resgate do patrimônio histórico ferroviário da cidade de Joinville - SC.

🔗 **Acesso ao Sistema Web (Live Demo):** [https://locomotiva.equipecom.workers.dev/](https://locomotiva.equipecom.workers.dev/)

## 🚀 Sobre o Projeto
A plataforma integra diversas áreas de conhecimento, incluindo:
- **Simulação 3D Web (Three.js):** Controle de uma locomotiva histórica com vagão de passageiros, operando em malha ferroviária.
- **Engenharia e Mecânica:** Visualização de dados e termodinâmica de máquinas a vapor.
- **Urbanismo Inclusivo:** Exploração da cidade virtual através dos olhos de cidadãos com diferentes necessidades, visando adequações da NBR 9050.
- **Integração com Ferramentas Industriais:** Scripts compatíveis com FreeCAD e guias de publicação em Unreal Engine 5.
